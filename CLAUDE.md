# otaman-cli — development notes

The `otaman` command-line binary for the Otaman platform: local project
management, bus operations, and runner/bridge clients.

## Working on this repo

- Python 3.10+. Dependencies resolve via `uv sync --extra test` with sibling
  checkouts of the other Otaman packages — see `.github/workflows/test.yml`
  for the exact workspace shape CI uses.
- Tests: `uv run pytest` (or `pytest` with the sibling `src` dirs on
  `PYTHONPATH`; see `pyproject.toml`). The suite isolates itself from any
  live Otaman workspace — keep it that way: never let a test touch a real
  bus or config outside `tmp_path`.
- Lint/format: `ruff check .` and `ruff format .`. CI enforces both with an
  exactly-pinned ruff version; the `[tool.ruff]` baseline in
  `pyproject.toml` is a floor — rule categories may be added, never removed.
- Command implementations live in `src/otaman_cli/commands/` and register
  via `CommandSpec`/`register()`; `main.py` is a thin dispatcher. New
  commands get a module there, not a `main.py` branch.
- All changes go through PRs against `main` with clear commit messages.

## AI assistants
