The launcher can now offer named profiles instead of always starting every
agent. Run it with no arguments and, at a terminal, it shows a menu — 1 full,
2 pick, then your profiles; run it with a profile name or its menu number to
skip the menu. Automation is unaffected: with no terminal it launches the full
set exactly as before, and a launcher with no `launch:` block in
launch-settings.yaml behaves exactly as it does today.

A profile can also seat the human console. The console is always placed on its
own private tmux server, never one the fleet can reach, and it inherits your
identity rather than inventing one — if it cannot tell who you are, it asks.
