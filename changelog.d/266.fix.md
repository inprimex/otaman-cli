`otaman doctor` no longer stops at a traceback partway through its report. A single
check whose finding used a different field name crashed the run, which silently
swallowed the pm-sync section, the pass/warn/fail verdict, the exit code and about
twenty later checks — the report ended mid-sentence and said nothing was wrong
because it never got as far as saying anything. Findings now render whichever field
carries their text, and one that carries none is printed as a visible, named
problem instead of taking the whole report down with it.
