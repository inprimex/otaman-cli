In the console, a row marked `◀ you` now says which action clears it — `◀ you (v)` for a
change awaiting spec-approval, `◀ you (otaman ratify)` for one that is complete but
unarchived, `◀ you (m: answer)` for one blocked on an unanswered decision. Previously the
marker named an obligation without naming the act, so pressing `v` on a row that needed
`otaman ratify` was refused with "nothing to review here" and left you with a marker you
could not act on. That refusal now names the action that does apply.

On the value lens, a change naming an outcome id the registry does not have now shows the
offending string on the row — `JTBD-58-llm-router-multi-backend (no such id)` — instead of
only contributing to a count. The five such changes on this program were all authoring
typos, and a typo is visible at a glance only if the string is.
