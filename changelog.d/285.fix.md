Approving or rejecting a spec-change request now clears the "approval pending" item that
proposing it had added to your queue. Previously nothing ever cleared those, so they
accumulated — 24 on this program, 21 of them for requests that had already been decided,
the oldest from early September — and every new request added one permanently. A queue
that says something is awaiting you when it is not teaches you to ignore the ones that
are.

Only the item belonging to the request you just decided is cleared, matched by the request
it names, and an item you had already acknowledged yourself is left exactly as you left
it. The command reports each one it clears rather than doing it silently.
