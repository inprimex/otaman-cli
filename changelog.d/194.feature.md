A shipped git credential helper removes the need for per-machine token
workarounds. Register a connection once and wire it with
`git config credential.helper '!otaman credential-helper'`; git then gets the
right credential at the moment it asks, resolved from wherever your secrets
already live. Nothing is written to disk — git's request to save the credential
is deliberately ignored — so a token never ends up in a config file, a remote
URL, or a helper script.
