A proposal whose approval or rejection has been archived no longer reappears as if it were
still awaiting you. Both the console's decision queue and `otaman check` looked for the
decision in the active bus only, so once routine cleanup moved an older announcement into
the archive, the proposal it had settled came back onto the mandatory list — which is the
same stale-queue problem the previous release fixed, reintroduced from the other end.
Fourteen decisions on this program were already archived.

Dispositions are now found in the archive too, and the scan is narrowed to the one agent
permitted to issue them, so it reads a few hundred files rather than every message on the
bus.
