`otaman send --type <t>` now stays in step with the message types otaman actually
accepts. The command keeps its own shorter list of the types a person sends by hand —
most valid types are emitted by a command or a daemon, not typed out — but that list had
silently fallen behind: `decision-required`, the message an agent is required to send
before it blocks on something only a human can decide, was missing, so the send was
rejected outright with `Unknown message type`.

Every type is now explicitly accounted for as either hand-sendable or machine-emitted,
and a check fails the build if a new one is left unclassified. An omission can no longer
look the same as a deliberate exclusion.
