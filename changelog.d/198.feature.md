Console actions now reflect what an outcome's status actually allows. Promote
and demote are available on outcome detail, and an action that cannot run is
refused with the reason the command itself would give — so the console and the
command line never disagree about what is possible.

Accepting a cost on a draft outcome is now refused with "requires status
Backlog — promote first". Previously it half-applied: the cost was marked
accepted and a solution chosen while the outcome stayed in draft, leaving money
approved against something with an incomplete statement.
