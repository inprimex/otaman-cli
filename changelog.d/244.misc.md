`otaman cleanup` now reads bus timestamps through otaman-core's shared parser rather
than its own copy, so the two cannot drift again — the drift is what made cleanup
treat 98.4% of a real bus as unparseable.

The declared Python requirement is now 3.11, which is what it has always effectively
been: otaman-core is a required dependency and requires 3.11, so a 3.10 install could
never resolve. Anyone on 3.10 now gets a clear refusal at install time instead of a
failure deeper in.
