`.agents/current-agent` is no longer consulted when resolving which agent you are. It had
remained as a deprecated last-resort fallback, so when every other signal was absent your
identity could still come from a single file shared by every session in the program —
whoever wrote it last. Identity now comes from the repo you are in: its `.otaman agent:`
field, or `platform.yaml` ownership. `otaman whoami --for-path <repo>` answers the same
question for a specific path.

`otaman doctor` now fails if that file reappears, naming the agent it claims and pointing
at the hook or runbook step that recreated it — deleting the file alone does not help if
something writes it again on the next commit.
