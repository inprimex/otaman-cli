`otaman doctor` now tells you why it exited non-zero. Eight different checks can
fail the run, and the report also contains several sections that only warn — so a
bare exit code left you (or your CI) scanning the whole output to guess which one
counted. The last line now names them: `Exit 1 — failing: 2 environment check(s)`.
A healthy run still exits 0 and says nothing extra.
