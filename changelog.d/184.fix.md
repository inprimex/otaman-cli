Bus messages are no longer lost when several are sent in the same second.
Dispatching a batch of spec changes, completing several tasks at once, or
approving a run of proposals could silently drop messages: each write landed on
a filename precise only to the second, so the later message overwrote the
earlier one and every command still reported success. Messages now carry the
change or subject in their filename, and no bus write can overwrite an existing
message — a genuine collision is written alongside rather than on top.
