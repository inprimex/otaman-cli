`otaman program list` shows every program on this machine with its lifecycle state,
and `otaman program show` tells you which program you are in — resolved the same way
everywhere: an explicit `--program`, else the directory you are standing in, else a
picker when you are at a terminal. Off a terminal it refuses and names the programs
you could have meant, instead of guessing or hanging; it only suggests `otaman init`
when there genuinely are none. A candidate directory that holds no program metadata is
marked as such rather than offered to you as somewhere to work.
