`otaman cleanup` no longer archives a message that was acknowledged as `read`.

`otaman ack --read` exists to keep a message visible while the recipient finishes
something else. Cleanup only checked that an acknowledgement file existed, never what
it said, so it was answering "has anyone acked this?" when the question is "is anyone
still working on it?" — and on one real bus 428 messages deliberately kept visible were
about to be archived out of `otaman check`.

A message is archived only once every recipient has reached a terminal state —
resolved, approved or rejected. An acknowledgement whose state cannot be read, or that
says something unrecognised, counts as unfinished rather than finished.
