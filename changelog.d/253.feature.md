`otaman propose` now shows you the spec gate's stage-1 score the moment you file —
the 0-100 number and every finding behind it, so a thin Evidence section or a repo
that does not exist is something you fix while you are still looking at it. The
score also rides the console's proposal rows and `otaman spec status` (with
`gate_score` in `--json`). The gate comments and never blocks: a flagged proposal is
filed and reaches the human either way. A pasted credential in a proposal body is
now caught by name — that check shipped months ago and had never once run.
