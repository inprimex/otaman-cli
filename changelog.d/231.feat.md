`otaman review security-gate <report.json|->` renders Hook C's security-gate
report in the review flow: per-layer verdicts, the disagreement flags a human
has to triage, and the suppression audit. The pass/block verdict comes from
otaman-core's single derivation, so the surface that emits a report and the
surface that renders it cannot disagree about whether it blocks.

It exits 0 clear, 1 blocked, and 2 when the report could not be read at all —
an unreadable report is never rendered as a pass. A layer the report says
nothing about is named as such instead of being left out, so a one-layer report
cannot read like a clean five-layer run.
