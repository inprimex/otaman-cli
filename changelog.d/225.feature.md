`otaman propose --authorizes <class>` records which classes of action a change
asks to be pre-authorized for. Naming one of the six never-pre-authorizable
actions is refused before anything is written, and the refusal says which one.
The envelope travels with the proposal and is shown when the change is reviewed,
with each class's runtime marker beside it. `otaman spec envelope` reports what
the live runtime actually does per class.
