`otaman send --type decision-required` now works. It is the message an agent is
meant to send the moment it needs a decision only you can make — instead of
freezing on a prompt nobody can see — but the command refused the type outright, so
not one had ever been sent. Three new flags carry what the message is for:
`--decision` (what you are being asked), `--blocks` (the work that is waiting) and
`--unblock-condition` (what would let it continue). Leaving any of them out is
refused with all three named, because a bare "I am blocked" is the silence this
replaces.
