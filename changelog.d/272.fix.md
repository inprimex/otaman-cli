`otaman policy routes` and `otaman doctor` now show a route exactly as the rest of the
platform records it, including whether it stays inside your tenant: a local route reads
`ollama/llama3@local (local)` where it previously read `ollama/llama3 (local)`. The
identifier is now produced in one place for every surface, so the same model run
locally and run off-tenant can no longer look like the same route — they are billed
and guarded differently, and the display says so.
