`otaman init --help` now prints help. It used to discard the unrecognised flag and run a
full init instead — which, from inside a repo, could offer to scan, scaffold the repo as
a program, and repoint its `.otaman` marker so every tool looked for the bus in the wrong
place. Unrecognised flags are now refused by name rather than silently dropped, and a
bare `otaman init` inside a repo that already names its program's directory refuses and
tells you where to run it instead.
