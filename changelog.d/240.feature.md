CLI self-management now lives under `otaman cli <verb>`, matching the
`otaman runner <verb>` shape already in use:

- `otaman cli install` — the new home of `otaman install-cli`, same behavior.
- `otaman cli interactive` — the interactive human console.

Both old spellings keep working, on different terms. `otaman install-cli` is a
deprecated alias: it still installs, and prints a notice naming the new home. A
later change removes it. `otaman -i` / `--interactive` is a permanent alias and
prints no notice — it is in every generated project instruction file and is not
going anywhere.

When the console extra is missing, the error now names both ways of invoking the
console along with the extra to install. It previously named neither, so a reader
who typed `otaman -i` had to infer the message was about the command they ran.
