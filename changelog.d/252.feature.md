The console's Messages lens is a grouped tree. The items that need you — spec
approvals, decision-required and anything urgent — render first and already
expanded; everything else groups by message type with a count, and routine
completions collapse to one count at the bottom. Which classes mandate review is
your program's `review-policy` block rather than arrival order, and when you have
not declared one the surface names the shipped default it is using. `→`/`←`
expand and collapse, Enter opens a message or toggles a group.
