Rows in the console's message queue now show the id you would cite them by, so
a request referenced elsewhere can be found in the list that displays it.

Long titles no longer push the sender and the action-key hint off the end of
the row. The row keeps `— from <agent> [a/A/x/d]` and shortens the title
instead, with an ellipsis — previously the most verbose items, the ones
hardest to act on, were the ones that lost the keys telling you how.

`otaman` can now read an outcomes register whose entries record what scope was
cut on a partially-delivered outcome. Before, one such entry made the whole
register unreadable.
