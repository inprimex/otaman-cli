`otaman init --update` now removes the retired `.agents/current-agent` file, reporting
which agent it had been claiming. `otaman doctor` already failed when that file was
present, but there was no command that cleaned it up — so the health check named a problem
you had to fix by hand. If removal fails, it says so rather than reporting success.

A reappearing file means something is still writing it, so the message points at the hook
or runbook step rather than only at the file.
