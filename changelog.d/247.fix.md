`otaman policy critics` and `otaman doctor` now say that the critics they list are the
set *before* the proposing agent is excluded. A proposal is never reviewed by the agent
that filed it, and these surfaces evaluate a gate rather than a proposal — so an
unlabelled list reads as the review roster and invites the conclusion that an agent
reviews its own work.

Where a gate resolves to exactly one eligible critic, both surfaces now warn: that
agent's own proposals exclude the whole set, so the declared fallback decides them — or
nothing does, which is reported more loudly.
