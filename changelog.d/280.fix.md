`otaman cleanup --help` and `otaman scan --help` now print usage instead of running the
command. Both parse their own options and ignored anything they did not recognise, so
asking for help read as "no options given" and the work went ahead: `cleanup --help` would
archive messages, and `scan --help` would write a draft `platform.yaml`. Archiving is a
recoverable move rather than a deletion, so nothing was lost where this happened, but it
was never asked for.

Help is now recognised anywhere in the arguments, not only in first position, so
`otaman cleanup --days 30 --help` is a request for help too. `otaman cleanup --help` also
now explains the part that surprises people: messages awaiting an ack are never archived
whatever their age, and only `--purge` destroys anything.
